antiSMASH Table Converter

Paste the URL of an antiSMASH results page and download a spreadsheet of every biosynthetic gene cluster it found — coordinates, cluster class, the most similar known cluster, and similarity scores, one row per region.

The index page, the job directory, or any download link from inside the job all work. Large jobs take a few seconds.

Why this exists

antiSMASH reports a genome's biosynthetic gene clusters as an interactive HTML page. That page is excellent for reading one region at a time, but it resists the thing people usually want next: a table they can sort, filter, and paste into a manuscript or a supplementary file. Pulling 30-odd regions out by hand — clicking each one, copying coordinates, noting the MIBiG match — is slow and error-prone, and it has to be redone every time the job is rerun.

This tool reads the results directly from the job's own data files and writes the table for you. Nothing is uploaded and no genome data is stored: the job URL you paste is fetched server-side, converted, and returned as a spreadsheet.

What you get

The workbook has three sheets. Regions is the main table, one row per region:

Known cluster hits lists every KnownClusterBlast hit for every region, in rank order, so you can see the runners-up rather than only the top call. Job info records the antiSMASH version, input filename, detection strictness, record and region counts, and the source URL — enough to make the table reproducible months later.

Finding your results URL

If you ran the job on the public antiSMASH server, it looks like https://antismash.secondarymetabolites.org/upload/bacteria-<job-id>/index.html. Copy it straight from your browser's address bar while viewing the report. A URL ending in #r12c1 because you clicked into a region is fine — the fragment is ignored.

Results from a local antiSMASH installation work too, as long as the output directory is reachable over HTTP from this server.

Where the numbers come from

Every value is read from the job's own output — nothing is recomputed or re-predicted. Coordinates, products, and gene counts come from regions.js, the data file the report itself uses to draw the region views. Similarity scores come from the same file's ClusterBlast, KnownClusterBlast, and SubClusterBlast result tables. Contig-edge warnings, the similarity confidence call, and the antiSMASH version are read from index.html.

A note on similarity percentages

KnownClusterBlast ranks its hits by how many genes match, not by similarity percentage, so its top-ranked hit is not always the one with the highest number. A region can rank a large, partially matched cluster above a single-gene cluster scoring 100%. The Similarity (%) column therefore always reports the score for the cluster named in that same row, and is left blank rather than borrowing an unrelated cluster's number. The full ranked list is on the second sheet if you want to judge for yourself.

Limits

  • Built and tested against antiSMASH 8 output. Older ClusterBlast result formats are handled where possible, but versions 5 to 7 have not been verified.
  • Very large jobs mean a large data file to parse; genome-scale runs with thousands of regions may time out and are better converted locally.
  • If the report's data file is unavailable, the table falls back to the overview table alone — fewer columns are filled, and the Job info sheet says so.
